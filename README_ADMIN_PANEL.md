## 💾 DATA STORAGE

### Current Implementation
- **Storage**: Browser localStorage
- **Auto-save**: All changes saved automatically
- **Persistence**: Data survives page refreshes and closing browser
- **No Backend Needed**: Perfect for development/testing

### View Your Data
1. Press F12 (DevTools)
2. Go to "Application" tab
3. Click "localStorage"
4. Find your domain
5. View `admin_data` key

### Reset Data (If Needed)
In browser console:
```javascript
localStorage.removeItem('admin_data')
location.reload()
```

## 🎓 HOW TO INTEGRATE WITH YOUR WEBSITE

### Step 1: Import the Hook
```javascript
import { useAdminData } from './admin/context/AdminDataContext'
```

### Step 2: Use in Your Pages
```javascript
export const Home = () => {
  const { data } = useAdminData()
  
  return (
    <>
      <h1>{data.hero.heading}</h1>
      <p>{data.hero.subheading}</p>
    </>
  )
}
```

### Step 3: Display Admin Data
Use `data.hero`, `data.services`, `data.portfolio`, etc. anywhere in your website!

## 🛠️ CUSTOMIZATION

### Change Admin Password
Edit `src/admin/context/AdminAuthContext.jsx`:
```javascript
const ADMIN_CREDENTIALS = {
  username: 'your_username',
  password: 'your_new_password',
}
```

### Change Colors
Find and replace Tailwind classes. Example:
```jsx
// From blue
className="from-blue-500 to-blue-600"
```
